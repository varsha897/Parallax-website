# Parallax Website

A Parallax Website built using HTML and CSS that showcases smooth scrolling effects and depth through background movement. It features multiple sections with fixed images and overlaying content, creating an engaging visual experience. Ideal for learning modern web design techniques and enhancing front-end development skills.
